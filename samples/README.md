# Sample G-code

Synthetic G-code files for trying Sprint without a slicer and for testing
the parser, analyzer, viewer and host. They are generated, deterministically,
by the `sprint-gcode` example:

```bash
cargo run -p sprint-gcode --example gen_samples
```

The files imitate the layout of real slicer output, but no slicer produced
them: each one says so in a comment near the top, and the print-time and
filament figures in their headers come from Sprint's own analyzer. The
`samples_are_up_to_date_and_small` integration test fails when a committed
file no longer matches the generator, so regenerate and commit after changing
it.

| File | Layout | What it contains |
|---|---|---|
| `calibration-cube.gcode` | PrusaSlicer 2.7 | 20 mm calibration cube, 0.2 mm layers (100 layers) |
| `twisted-vase.gcode` | Cura 5 (`;FLAVOR:Marlin`) | 60 mm twisted hexagonal vase in spiral (vase) mode, 300 layers |
| `arcs-test.gcode` | plain Marlin | G2/G3 coverage: circles, R-form arcs, a 50-turn helix |

## calibration-cube.gcode

A PrusaSlicer-style file for a Marlin 2 printer with a 250 x 210 mm bed.

* Header: `; generated by PrusaSlicer 2.7.1+win64 ...`, two PNG thumbnails
  (16x16 and 220x124, an isometric orange cube on a transparent background)
  in `; thumbnail begin` / `; thumbnail end` blocks, extrusion-width notes.
* `M73 P/R` and `Q/S` progress at every layer, `M201`/`M203`/`M204`/`M205`
  machine limits.
* Start G-code under `;TYPE:Custom`: `M140`/`M104`/`M190`/`M109`, `G28`,
  `G29`, a purge line at Y-3.
* Per layer: `;LAYER_CHANGE`, `;Z:`, `;HEIGHT:`, `;BEFORE_LAYER_CHANGE`,
  `;AFTER_LAYER_CHANGE`, `;TYPE:` and `;WIDTH:` annotations, relative
  extrusion (`M83`) with PrusaSlicer's rounded-rectangle flow model.
* Features: one skirt loop on the first layer, two perimeters (inner, then
  external), 20% rectilinear infill alternating 45/135 degrees with
  connected lines, 3 bottom and 3 top solid layers (`Solid infill`, last
  layer `Top solid infill`).
* 0.8 mm retractions with 0.4 mm Z hop on longer travels; fan off on the
  first layer, `M106 S255` from the second.
* End G-code, then the summary (`; filament used [mm] = ...`, `; estimated
  printing time (normal mode) = ...`) and the alphabetical
  `; prusaslicer_config = begin` ... `end` block.

## twisted-vase.gcode

A Cura-style file for a 220 x 220 mm Marlin printer.

* Header: `;FLAVOR:Marlin`, `;TIME:`, `;Filament used: ...m`,
  `;Layer height:`, `;MINX:` ... `;MAXZ:`, `;Generated with
  Cura_SteamEngine 5.6.0`; Cura's default start G-code with the two-line
  purge at Z 0.28 before `;LAYER:0`.
* Absolute extrusion (`M82`), 5 mm retractions, `;LAYER_COUNT:300`,
  `;LAYER:n`, `;MESH:twisted-vase.stl`, `;TYPE:WALL-OUTER` / `;TYPE:SKIN`,
  `;TIME_ELAPSED:` after every layer, fan ramping 0/85/170/255 over the first
  layers.
* Three flat bottom layers (wall plus zig-zag skin), then 297 spiral layers:
  one continuously rising outer wall, one `;LAYER:` marker per revolution.
  The outline is a soft hexagon whose radius follows a smooth bulge-neck-lip
  profile and which twists by 120 degrees with eased ends, sampled at 144
  points per revolution.
* Cura's end G-code (`G91` retract and lift, `G90`) and the `;SETTING_3`
  profile lines.

## arcs-test.gcode

Absolute extrusion, no slicer header, no layer markers. Sections:

* A, B: full circles in I/J form, clockwise and counter-clockwise
  (start == end).
* C: an S-curve of six half circles in R form.
* D: a 270 degree arc using a negative R.
* A travel arc (no E).
* E: a spiral of quarter arcs with growing radius, joined by short `G1`
  steps.
* F: half-circle bumps in relative mode (`G91`, which also makes E relative).
* G: a full circle in inch units (`G20`).
* A tube of ten stacked full circles, continued by one `G2 ... Z12 P49`
  command (50 turns, a helix rising 10 mm), then two R-form half turns that
  keep climbing. Without layer markers the helix is grouped into ~0.2 mm
  layers by height.
